Minimal, self-hosted workflow automation. You own your workflow files.

[Website](https://zerodot.io) · [Get started](https://github.com/zerodot-io/zerodot#quickstart)

## Repositories

- [zerodot](https://github.com/zerodot-io/zerodot): the app. AGPL-3.0-only.
- [nodes](https://github.com/zerodot-io/nodes): official node packages.
- [create](https://github.com/zerodot-io/create): template for a community node package.
- [website](https://github.com/zerodot-io/website): the zerodot.io website.

## Contribute

Open an issue or a pull request in [zerodot](https://github.com/zerodot-io/zerodot). To build your own node, start from the [create](https://github.com/zerodot-io/create) template.
